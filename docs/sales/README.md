## Целевые сегменты (приоритет)

1. **ТВ каналы** — автоматизация эфира, аудит, proof-of-play
2. **Банки** — управление очередями и экранами в филиалах
3. **Ритейл** — единообразие контента на экранах в точках продаж
4. **Госсектор** — информирование, очереди, оповещения

## Ключевые USP для продаж

- Контент на экране за < 2 мин
- Оверлеи реального времени (< 2 сек задержки)
- Полный аудит + As-Run отчёты
- Офлайн-режим (кеш на устройстве)
- Цена в 3-5× ниже западных аналогов
- Локальная поддержка на русском
